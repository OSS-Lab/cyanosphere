# CyanoSphere

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23498485.svg)](https://doi.org/10.5281/zenodo.23498485)

Code and derived data for *Convergent metabolic functions in cyanobacterial
communities emerge from imposed and community-derived niches* (Scarampi,
Duxbury, Coates, Eren, Soyer).

Two experiments on freshwater photosynthetic communities from Draycote
Reservoir, UK:

1. **Long-term enrichments.** Eight lake samples, taken at different times and
   places, each enriched independently for over a year in the same medium
   without organic carbon, under a 12:12 h light:dark cycle, and compared with
   eight samples of the reservoir.
2. **Media experiment.** One lake sample propagated for ten passages in three
   media: full medium (V), no vitamins (NV), no vitamins and no nitrate (NVNN).

Function is quantified on assembled contigs, without genome binning, with two
metrics per KEGG module per sample:

| Metric | What it follows | Definition |
|---|---|---|
| coverage-based | how abundant the carriers of a function are | anvi'o module coverage: mean read coverage of the module's genes |
| count-based | how widely a function is held across community members | stepwise module copy number / number of populations (97% RpL19 EcoPhylo clusters; RpS16 in the media experiment) |

We hypothesised that a function imposed by the medium rises on both metrics,
and that a function selected by conditions the community generates may rise on
the count-based metric alone.

**[WORKFLOW.md](WORKFLOW.md)** is the reproducible workflow: every step from raw reads to the paper,
with the figures and what they show, and how to apply the two metrics to other metagenomes with
`analysis/two_metrics.py`.

## Quick start

```bash
git clone https://github.com/OSS-Lab/cyanosphere.git
cd cyanosphere
conda env create -f environment.yml
conda activate cyanosphere
cd analysis
python taxonomy.py        # Figs 1-2: diversity, lineages, composition, similarity by level
python function.py        # Fig 3, Table 1, two-metric robustness (Table S6), MAG checks
python media.py           # Fig 4 analysis, Table S7           (reads function.py outputs)
python supplementary.py   # SI tables and figures
python figures.py         # composes Figs 1-4 (outputs/FIG1-4.pdf)
```

The five commands take a few minutes on a laptop, read only `data/`, write only
`outputs/` (created on the first run, not tracked), and use fixed random seeds,
so a fresh clone regenerates every number, table and figure panel in the paper.

## Layout

```
analysis/    the six modules below compute every figure panel, table and statistic in the paper;
             two_metrics.py is the standalone method
data/        the derived tables the analysis reads (~20 MB); provenance of each in data/README.md

docs/        images for WORKFLOW.md (docs/make_images.py renders them from outputs/)

```

## Analytical choices

* **Populations** are 97% nucleotide-identity clusters of ribosomal protein L19
  (RpS16 in the media experiment) from anvi'o EcoPhylo. A population is present
  in a sample when its coverage is above zero. Clusters without a GTDB phylum
  take phylum to family (never genus) from the nearest named tip on the marker
  tree (`common.place_on_tree`); below phylum, each unnamed cluster is its own unit.
* **Tests.** Two-sided Wilcoxon rank-sum with an exact permutation null (all
  12,870 or 715 group assignments, mid-ranks for ties); Benjamini-Hochberg within
  each metric and comparison; significant at q < 0.05 and |log2FC| > 0.5.
* **Coverage is not depth-normalised** in the tests, so that the two metrics stay
  distinct; normalising by sequencing depth changes 1.7% of classes (Table S6).
  Dividing by total module coverage is used only for ordinations
  (`common.compositional`).
* **Ordinations** are PCoA on Bray-Curtis dissimilarities of relative coverage,
  with PERMANOVA (reported as p and R2) and PERMDISP on the same distances, 9,999
  permutations. Convergence is the similarity of pairs of samples within a group
  (1 - Bray-Curtis), enrichment pairs against reservoir pairs; it is repeated
  with Hellinger, Jaccard, weighted and unweighted UniFrac and RpS16 (SI Fig S6).
* **MAG attribution** (Fig 3E, Table S4) links MAG coverage to each genome by
  sequence (`pipeline/05_link_mags_to_bins.py`), never by name.
* **Plastid-like clusters.** A cluster placed inside the cyanobacteria but further
  than `figures.PLACE_MAX` (0.6) from any named tip cannot be told from a plastid
  homologue; in the media cultures one such RpS16 cluster is reported as
  unassigned (Fig 4B, SI Fig S14).

## Pipeline (HPC)

`pipeline/` holds the jobs that turned reads into the tables in `data/`, as they
were run on the University of Warwick clusters with Slurm. Paths in the scripts
refer to those clusters and must be adapted elsewhere; tool versions are given in
the paper's Methods.

| Step | Folder |
|---|---|
| per-sample assembly (metaSPAdes) and anvi'o contigs databases and profiles | `01_assembly_metaspades/` |
| per-lineage co-assembly and binning (STRONG), GTDB-Tk, anvi'o per co-assembly | `02_strong_coassembly/` |
| KOfam annotation, EcoPhylo (RpL19, RpS16), dereplication, `anvi-estimate-metabolism` | `03_anvio_ecophylo_metabolism/` |
| symclatron lifestyle predictions | `04_symclatron/` |
| sequence link between dereplicated MAGs and their bins | `05_link_mags_to_bins.py` |
| NCBI MAG export | `06_ncbi_submission/` |
| export of EcoPhylo coverage, assembly statistics and KEGG tables to `data/` | `07_export_raw_tables.py` |
| media MAG tables | `08_media_mag_tables.py` |
| media P10 reads mapped to the shared genome reference | `09_media_reads_to_MAGs/` |
| earlier-passage samples profiled on the final RpL19 clusters (Fig 1) | `10_fig1_lineages/` |
| phylogenomic tree of the 88 MAGs (SI Fig S8) | `11_mag_phylogeny/` |
| eukaryotic signal in the media cultures | `12_media_eukaryote/` |

## Data availability

Raw reads of the eight enrichment end-points and the fourteen media samples are
at NCBI under BioProject PRJNA1432497 (`data/sra_accessions.csv`); the eight
reservoir metagenomes (W samples) are to be deposited before publication. The
88 dereplicated MAGs have BioSample accessions under the same BioProject
(`data/mag_biosample_accessions.tsv`). anvi'o databases and other large
intermediates are archived separately (see the paper's Data availability statement).
